Название команды                                                                | Результат выполнения
--------------------------------------------------------------------------------|----------------------
pytest test_api1_1.py -v                                                        | Запуск всех тестов
pytest test_api1_1.py::(Название нужного класса) -v                             | Запуск нужного класса
pytest test_api1_1.py -k "positive" -v                                          | Сапуск только негативных кейсов
pytest test_api1_1.py -k "negative" -v                                          | Запуск только позитивных кейсов
pytest test_api1_1.py::(Название нужного класса)::(Название нужной функции)s -v | Запуск нужной функции
